# Welcome to the Pazuzu Wiki

Pazuzu is a **Quadtree-AMR Flux Reconstruction Solver**.

This project implements a high-order Computational Fluid Dynamics (CFD) solver using:
- **Flux Reconstruction (FR)** for high-order accuracy.
- **Cartesian Quadtree** mesh topology for efficient adaptive mesh refinement.
- **Block-Adaptive Mesh Refinement (AMR)** for dynamic resolution.
- **Immersed Boundary Method (IBM)** for handling complex geometries without body-fitted meshes.
